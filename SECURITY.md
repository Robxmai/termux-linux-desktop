# Security Policy

## Safe Reporting

Do not submit account credentials, bearer values, session identifiers, API
authentication material, private IP addresses or hostnames, proprietary game
or runtime files, or DRM/anti-cheat bypasses. Remove such material from issue
descriptions, logs, screenshots, patches, and attachments before sharing them.

Vulnerability details must not be posted in public issues or discussions; they
must be sent through https://github.com/Robxmai/termux-linux-desktop/security/advisories/new.

Please provide a clear description, affected component or revision, concise
reproduction steps, and the security impact. Keep reports limited to the
minimum sanitized evidence needed to reproduce the issue.

## Scope

This policy covers the scripts, documentation, and configuration published in
this repository. Third-party Android, Termux, Linux distribution, display
server, compatibility-layer, game, and application issues should be reported
to their respective maintainers as well.

Do not use this project to bypass software licensing, DRM, access controls, or
anti-cheat protections.
